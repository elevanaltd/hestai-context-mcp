===AUDIENCE_VIEW_SEEDS===
GLOBAL::"ADR-0013 defines how hestai-context-mcp makes session memory portable across machines via a pluggable StorageAdapter, without syncing raw local state and without compromising credential safety."
AGENT::"PSS uses a StorageAdapter protocol. LocalFilesystem is the default; remote carriers are optional. State is classified as LOCAL_MUTABLE, PORTABLE_MEMORY, or DERIVED_PROJECTION — unknown state fails closed to LOCAL_MUTABLE. Lifecycle: clock_in restores, get_context reads snapshot only (never calls adapters), clock_out archives then publishes. Identity tuple must match on restore or return structured error. Redaction provenance is mandatory before any write_artifact call. No custom Git refs (R11). Remote auth/hosting deferred (R12)."
REVIEWER::"Risk gate: verify R2 (get_context not in adapter call graph), R5 (lifecycle sequence preserved), R6 (redaction provenance gate not bypassed), R11 (no custom Git refs introduced). ADR-0013 covers five PROD immutables; violation of I1, I2, I3, I5, or I6 requires requirements-steward escalation. B2 gate requires workbench integration; do not merge B2 work without North Star §6 gate check."
ONBOARDING::"ADR-0013 solves the fresh-clone problem: a new machine can restore shared session memory without the raw .hestai/state/ folder. It works by publishing redacted memory artifacts through an optional storage adapter. LocalFilesystem is the default, so everything works offline. The raw state folder never goes to the cloud."
